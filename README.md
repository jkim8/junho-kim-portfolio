# Junho Kim Portfolio

React + Vite portfolio with a pinned chapter-based scroll story, animated operations dashboard, responsive sections, active navigation, scroll progress, and subtle hero parallax.

## Run in VS Code

1. Unzip this folder and open it in VS Code.
2. Open Terminal → New Terminal.
3. Run `yarn install` once.
4. Run `yarn dev` and open the local URL shown in the terminal.

The latest résumé PDF is in `public/` and is linked from the hero and contact sections.

To build a production version, run `yarn build`; the output goes to `dist/`. This project supports Node.js 16 or newer.
